*Data Description:

adult.csv: The original census income data. This data was extracted from the 1994 Census bureau database by Ronny Kohavi and Barry Becker (Data Mining and Visualization, Silicon Graphics), which consists of reasonably clean records extracted from the 1994 Census Bureau database and is widely used to evaluate the classification algorithms. The data records 14 attributes including gender, race, marriage and education length of more than 30,000 people.


*Code Description:

Real-data.R: The R code for main census income case study. 

function_PASS.R: The R code for functions used in the main code file.

algoclass_PASS.R: The R code for algorithm (model) classes used in the main code file.
