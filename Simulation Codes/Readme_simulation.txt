*This folder contains codes for all simulation results presented in the article and the supplementary material.


*Code Description:

Simulation_REG.R: The R code for simulations of the regression setting (Scenario A). The replications are implemented by parallelization.

Simulation_CLA.R: The R code for simulations of the classification setting (Scenario B). The replications are implemented by parallelization.

Illustrating example.R: The R code for plotting the illustrating example in Section C.1 in the supplementary material.

Simulation_Supp.R: The R code for all additional simulations in the supplementary material.

function_PASS.R: The R code for functions used in the simulations.

algoclass_PASS.R: The R code for algorithm (model) classes used in the simulations.
